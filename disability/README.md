## Method and limits

Pilot list built from retrievable PA 211 items plus secondary lists (Inglis Snyder County Quick Start Guide, Feb 2025; Union-Snyder Community Action Agency Human Services directory, July 2025; PA DHS county guides and state programme pages). Every item checked against the organisation's own website/page or a state programme page. Own site beats directory; directory beats a third-party aggregator. Every address verified by exact geocoding, never by ZIP or town name alone (Danville = Montour County; Milton and Sunbury = Northumberland County; Williamsport = Lycoming County; Altoona = Blair County; Lewisburg = Union County; Camp Hill = Cumberland County; Selinsgrove = Snyder County).

Late in this check the page-text fetch service returned a 429 rate limit on own-site page fetches (TechOWL ATRC page, CSIU preschool EI page, CSSS About page, PA OVR directory page). Those requests were NOT retried; affected items rest on search results from the organisation's own domain or a state programme page, and unconfirmed details are marked UNVERIFIED rather than published as fact. A live-browser re-check is outstanding — see the pre-send re-check list in the audit report.

This audit checks contact information only. It does not assess service quality, eligibility outcomes, or benefits/legal advice. No organisation is called closed or defunct. UNVERIFIED means the own-site evidence was not found in this check, not that a service has ended.

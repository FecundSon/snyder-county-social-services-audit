## Method and limits
Pilot list built from retrievable PA 211 listings, the Union-Snyder
CAA Human Services Directory (July 2025), the Inglis Quick Start
guide for Snyder County, PA DHS documents, and secondary directories;
every item then checked against the organisation's own website/page
via public web search and page-text fetches. Own site beats directory;
directory beats a third-party aggregator. No organisation, PA 211, or
anyone else was contacted. Addresses were checked by exact address,
never by ZIP or town name alone; Lewisburg, Milton, Mifflinburg, and
Lewistown are in other counties and are out of scope as locations.
No waitlist, funding, or seasonal status is presented as permanent —
every such status is as found on 2026-11-15 only. No organisation is
called closed or defunct: items marked UNVERIFIED are unconfirmed, not
closed. No domestic-violence safe-house address appears anywhere in
this audit.
